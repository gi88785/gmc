# 📱💻🎉 Gilles & Marie Family Calendar App (GMC)

A simple, clean, cross-platform Flutter app to track and get notified about important family events like birthdays, baptisms, marriages, and more!

## 📦 Features

- Add family event dates
- View Upcoming birthdays/events list
- Local notifications for next-day birthdays/Events (12oclock) 
- Weekly Sunday reminders for upcoming events/birthdays
- Cross-platform: Android, iOS, Windows, Mac, Linux, Web (via Flutter)
